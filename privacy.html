Privacy Policy

Last updated: November 2026

1. Overview

My Pharmacy is an offline desktop application. We are committed to protecting user privacy. This policy outlines how our software handles user credentials, authentication tokens, and application data.

2. Data Collection and Storage

The application operates locally on the user's workstation. All clinical databases, transaction logs, inventory tallies, and patient records are stored locally inside the application's offline data files. We do not transmit or sell user information to third-party databases.

3. Google API Data & OAuth Usage

When Google authentication or Google APIs are utilized within the desktop client:

  • Google user data (such as basic profile and email) is accessed strictly to authenticate the operator or enable optional user-requested integrations (e.g., automated cloud backup).
  • OAuth tokens received from Google are stored securely in encrypted local storage on the host machine.
  • No Google user data is shared, transferred, or disclosed to third parties.

4. Security

Local databases and license information are protected using industry-standard local encryption mechanisms. Users retain full physical and logical control of their data files.

5. Contact

If you have questions regarding this policy, contact the project maintainers via our repository at GitHub Repository.
